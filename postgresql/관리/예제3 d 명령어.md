# 예제3. \d 명령어

`\d` 명령어와 그 변형들을 실습해 보실 수 있도록, `scott` 스키마에 다양한 객체를 생성하는 예제 스크립트를 준비했습니다. 이 스크립트를 실행한 뒤 하나씩 조회해 보시면 감이 확 오실 거예요.

---

### 1. 실습용 객체 생성 스크립트

아래 내용을 복사해서 psql에 붙여넣거나, `test_objects.sql` 파일로 만들어 `\i` 명령어로 실행해 보세요.

SQL

```jsx
-- 1. 테이블 생성 (Table)
CREATE TABLE scott.projects (
    proj_id SERIAL PRIMARY KEY,
    proj_name TEXT NOT NULL,
    start_date DATE DEFAULT CURRENT_DATE
);

 -- DEFAULT는 테이블 정의 시 설정된 CURRENT_DATE가 들어감
INSERT INTO scott.projects (proj_name, start_date) 
VALUES 
    ('Inventory System', '2026-05-01'),
    ('Customer Portal', '2026-06-15'),
    ('Batch Job Optimization', DEFAULT);

-- 2. 뷰 생성 (View)
CREATE VIEW scott.v_active_projects AS
SELECT * FROM scott.projects WHERE start_date >= '2026-01-01';

-- 3. 인덱스 생성 (Index)
CREATE INDEX idx_proj_name ON scott.projects(proj_name);

-- 4. 간단한 함수 생성 (Function)
CREATE OR REPLACE FUNCTION scott.get_now() 
RETURNS TIMESTAMP AS $$
BEGIN
    RETURN NOW();
END;
$$ LANGUAGE plpgsql;
```

---

### 2. `\d` 명령어 체감하기 (실습 순서)

객체를 다 만드셨다면, 이제 다음 명령어들을 순서대로 입력하며 차이점을 확인해 보세요.

| **명령어** | **확인 내용** | **비고** |
| --- | --- | --- |
| **`\d`** | 현재 스키마의 테이블, 뷰, 시퀀스 목록 | 요약본 확인 |
| **`\dt`** | `projects` 테이블만 목록에 나옴 | **T**ables |
| **`\dv`** | `v_active_projects` 뷰만 목록에 나옴 | **V**iews |
| **`\di`** | `idx_proj_name`과 PK 인덱스 목록 | **I**ndexes |
| **`\df`** | `get_now` 함수 정보 확인 | **F**unctions |
| **`\d scott.projects`** | 테이블의 컬럼, 타입, 인덱스 상세 구조 | 특정 객체 상세 |
| **`\d+ scott.projects`** | 위 정보에 'Storage'와 'Description' 추가 | 더 자세히(+) |
