**2.2 리눅스 설치 시작**

VirtualBox에서 생성한 VM을 시작하고 ISO 파일을 삽입한다.

![image](images/320792772-d74a2a06-9db7-4180-b0cd-d57942f999f6.png)

Install Oracle Linux 8.4.0를 선택한다.

![image](images/320792998-87451726-8f58-41ce-82f1-7dfd0897e0f3.png)

언어는 한국어 또는 영어를 선택한다.

![image](images/320793383-79d20078-c189-41ed-bf18-7b1b97f8b627.png)

이제 모든 항목을 하나씩 설정해줄 것이다.

- **설치 목적지(디스크 파티션)**

![image](images/321826772-66742f21-676d-4321-b8e1-1e5b24c54599.png)

(swap은 메모리의 1~2배 정도 설정한다.)

![image](images/321827022-5b2fa1ae-2dfb-45fd-a486-10b3a9023c11.png)

- **네트워크 및 호스트 이름**

![image](images/322206470-9f6ab869-8b0b-4c58-8353-68ca32c0eb24.png)

호스트 이름을 rac1로 변경하고 적용한다.

![image](images/319861193-56aff0d6-fbe3-4a2a-812b-598473aa6227.png)

시작과 동시에 네트워크 자동연결 옵션을 체크한다.

![image](images/321968313-bbadbcec-054c-4faf-8fa8-033d249a2f4c.png)

ipv4를 수동으로 설정한다. 서브넷 마스크의 255.255.255.0은 24로 입력해도 같은 값이다.

![image](images/319861476-665be6c6-6b27-4e09-88d6-8d8f386088b1.png)

DNS서버는 윈도우의 cmd 창에서 ipconfig -all 할 때 나오는 DNS서버 이름으로 설정한다.

![image](images/319861507-66ef3e50-a0a4-4ce8-beb6-b8f0e53353f0.png)

ipv6는 무시한다.
