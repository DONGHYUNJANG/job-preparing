# 오라클 12C 스터디용 스키마 설치확인

---

</aside>

### 1. 핵심 내용: 스키마별 객체 정보 조회 뷰

데이터가 잘 들어갔는지 확인하려면 오라클의 **데이터 딕셔너리 뷰(Data Dictionary Views)**를 활용해야 합니다.

- **`DBA_USERS`**: 생성된 스키마(HR, SH, OE 등)가 `OPEN` 상태인지 확인.
- **`DBA_TABLES`**: 특정 사용자가 소유한 테이블 목록 확인.
- **`DBA_OBJECTS`**: 테이블 외에 인덱스, 뷰, 시퀀스 등이 정상적으로 생성되었는지 확인.

---

### 2. 단계별 데이터 확인 방법

### ① 스키마 계정 상태 확인

먼저 설치하려고 했던 계정들이 정상적으로 생성되고 잠겨있지 않은지 확인합니다.

SQL

```jsx
SELECT username, account_status, created 
FROM dba_users 
WHERE username IN ('HR', 'OE', 'SH', 'IX', 'BI', 'PM')
ORDER BY username;
```

> **Tip:** 만약 `LOCKED` 상태라면 `ALTER USER HR ACCOUNT UNLOCK;` 명령어로 풀어줘야 합니다.
> 

### ② 스키마별 테이블 개수 확인

각 스키마에 테이블이 몇 개나 생성되었는지 한눈에 봅니다.

SQL

```jsx
SELECT owner, COUNT(*) as table_count
FROM dba_tables
WHERE owner IN ('HR', 'OE', 'SH', 'IX', 'BI', 'PM')
GROUP BY owner;
```

- **HR**: 보통 7개 테이블
- **SH**: 보통 9~18개 테이블 (버전별 상이)

### ③ 주요 테이블 데이터 건수(Row Count) 확인

실제로 데이터가 밀려 들어갔는지 핵심 테이블 위주로 조회해 봅니다.

SQL

```jsx
- HR 스키마 (가장 기본)
SELECT 'HR.EMPLOYEES' as table_name, COUNT() FROM hr.employees
UNION ALLSELECT 'HR.DEPARTMENTS', COUNT() FROM hr.departments;
- SH 스키마 (데이터가 많음)
SELECT 'SH.SALES' as table_name, COUNT() FROM sh.sales
UNION ALLSELECT 'SH.CUSTOMERS', COUNT() FROM sh.customers;
```
