사고 시점(지우기 직전)으로 타임머신을 태우는 **Flashback Query** 명령어들을 정리해 드릴게요. 

---

### 1. 지워진 데이터 눈으로 먼저 확인하기
테이블 전체를 돌리기 전에, 지워진 데이터가 잘 보이는지 먼저 확인하세요. (약 5분 전 상태 조회)

```sql
SELECT * FROM SCOTT.DEPT 
AS OF TIMESTAMP (SYSTIMESTAMP - INTERVAL '5' MINUTE);
```
* 만약 특정 시간으로 지정하고 싶다면:
```sql
SELECT * FROM SCOTT.DEPT 
AS OF TIMESTAMP TO_TIMESTAMP('2026-04-04 12:00:00', 'YYYY-MM-DD HH24:MI:SS');
```

---
### 2. 테이블 전체를 과거로 돌리기 (Flashback Table)
만약 지워진 레코드가 너무 많아서 테이블 자체를 통째로 과거 시점으로 되감고 싶다면 이 방법을 쓰세요. (단, Row Movement가 활성화되어 있어야 합니다.)

```sql
-- 1. 행 이동 활성화 (최초 1회 필수)
ALTER TABLE SCOTT.DEPT ENABLE ROW MOVEMENT;

-- 2. 10분 전 상태로 테이블 되감기
FLASHBACK TABLE SCOTT.DEPT TO TIMESTAMP (SYSTIMESTAMP - INTERVAL '10' MINUTE);
```



---

### ⚠️ 주의사항: "골든 타임"이 있습니다!
Flashback Query는 **Undo 영역**에 저장된 데이터를 사용합니다. 
* DB에 트랜잭션이 너무 많으면 Undo 데이터가 금방 덮어씌워져서 `ORA-01555 (Snapshot too old)` 에러가 날 수 있습니다.
* **지금 바로 실행하세요!** 시간이 지날수록 복구 확률은 떨어집니다.
