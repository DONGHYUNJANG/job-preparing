## 📑 오라클 테이블 복구(Drop Purge) 통합 스크립트

### **STEP 1. 사고 로그 분석 (LogMiner)**
삭제된 정확한 시점과 SCN을 찾아내는 단계입니다.

```sql
-- 1. 분석할 아카이브 로그 등록 (오늘 날짜 시퀀스 확인 후 파일명 변경)
EXEC DBMS_LOGMNR.ADD_LOGFILE(LogFileName => '/u01/app/oracle/fast_recovery_area/ORA19/archivelog/2026_04_04/o1_mf_1_2_nx0rvx8w_.arc', Options => DBMS_LOGMNR.NEW);

-- 2. 로그마이너 시작 (온라인 카탈로그 사용)
EXEC DBMS_LOGMNR.START_LOGMNR(OPTIONS => DBMS_LOGMNR.DICT_FROM_ONLINE_CATALOG);

-- 3. 삭제 기록 및 SCN 확인 (결과에서 SCN과 TIMESTAMP 기록)
SELECT SCN, TO_CHAR(TIMESTAMP, 'YYYY-MM-DD HH24:MI:SS') AS TIME, SQL_REDO 
FROM V$LOGMNR_CONTENTS 
WHERE SQL_REDO LIKE '%drop table%purge%' AND SEG_OWNER = 'SCOTT';

-- 4. 로그마이너 종료 (자원 해제)
EXEC DBMS_LOGMNR.END_LOGMNR;
```

---

### **STEP 2. 복구 환경 준비 (OS Level)**
RMAN이 임시 작업을 수행할 공간을 만듭니다.

```bash
# 리눅스 쉘에서 실행
mkdir -p /u01/app/oracle/oradata/temp_recovery
chown -R oracle:oinstall /u01/app/oracle/oradata/temp_recovery
chmod -R 775 /u01/app/oracle/oradata/temp_recovery
```

---

### **STEP 3. 테이블 정밀 복구 (RMAN)**
백업본에서 특정 테이블만 추출하여 현재 DB로 밀어넣습니다.

```bash
# RMAN 접속
rman target /

# 테이블 복구 실행 (SCN 번호는 STEP 1에서 찾은 값의 -1을 입력)
RECOVER TABLE SCOTT.DEPT
    UNTIL SCN 2840614
    AUXILIARY DESTINATION '/u01/app/oracle/oradata/temp_recovery'
    REMAP TABLE 'SCOTT'.'DEPT':'DEPT_RECOVERED';
```

---

### **STEP 4. 최종 데이터 반영 (SQL)**
복구된 테이블에서 원본 테이블로 데이터를 옮깁니다.

```sql
-- 1. 복구된 데이터 확인
SELECT COUNT(*) FROM SCOTT.DEPT_RECOVERED;

-- 2. 원본 테이블로 데이터 복사 (원본이 삭제된 상태라면 새로 생성)
CREATE TABLE SCOTT.DEPT AS SELECT * FROM SCOTT.DEPT_RECOVERED;

-- 3. (옵션) 기존 테이블이 있다면 INSERT 사용
-- INSERT INTO SCOTT.DEPT SELECT * FROM SCOTT.DEPT_RECOVERED;
-- COMMIT;

-- 4. 임시 테이블 삭제 (검증 완료 후)

```

### 💡 실무자용 핵심 체크리스트
* **SCN vs TIME**: 시간보다는 **SCN**으로 복구하는 것이 가장 정확합니다 (초 단위 오차 방지).
* **Space**: `/temp_recovery` 공간은 전체 백업 파일 크기를 감당할 수 있을 만큼 넉넉해야 합니다.
* **Privilege**: `SYSDBA` 권한이 있는 계정으로 수행해야 합니다.
