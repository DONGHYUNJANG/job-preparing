# TTS 테이블스페이스 이름 및 경로 규칙

## 핵심 원칙

- **테이블스페이스 이름**: 소스 DB와 타겟 DB에서 동일하게 유지됨 (자동 생성)
- **데이터 파일 경로**: 타겟 DB에서 변경 가능 (impdp 시 지정)
- **스키마 이름**: REMAP_SCHEMA 옵션으로 변경 가능

## 테이블스페이스 이름 규칙

오라클이 메타데이터를 읽을 때 저장된 테이블스페이스 이름을 그대로 가져와 타겟 DB에 등록합니다.

- **소스 DB**: TBS_SALES
- **타겟 DB**: TBS_SALES (자동 생성)
- **주의사항**: 타겟 DB에 동일 이름의 테이블스페이스가 있으면 충돌 발생

## 데이터 파일 경로 변경

impdp 시 TRANSPORT_DATAFILES 옵션으로 새 경로 지정:

```bash
impdp system/password \
  TRANSPORT_DATAFILES='/u01/app/oracle/oradata/target/tbs_sales01.dbf' \
  DIRECTORY=dpump_dir \
  DUMPFILE=tbs_metadata.dmp
```

## 테이블스페이스 이름 변경이 필요한 경우

- **문제점**: REMAP_TABLESPACE 옵션이 TTS에서는 작동하지 않는 경우가 많음
- **해결책 1**: 소스 DB에서 ALTER TABLESPACE ... RENAME TO로 미리 변경
- **해결책 2**: 임포트 후 타겟 DB에서 이름 변경

## 요약

- 테이블스페이스 이름은 소스와 타겟이 동일
- 데이터 파일 경로는 변경 가능
- 스키마 이름은 REMAP_SCHEMA로 변경 가능
