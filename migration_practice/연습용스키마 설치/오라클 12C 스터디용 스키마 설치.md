# 오라클 12C 스터디용 스키마 설치

> 다운로드
> 

https://docs.oracle.com/en/database/oracle/oracle-database/12.2/comsc/schema-diagrams.html#GUID-D268A4DE-BA8D-428E-B47F-80519DC6EE6E

> 사전준비 - OS 터미널에서 경로 치환 (필수 ⭐)
> 

```jsx
cd /home/oracle/db-sample-schemas-12.2.0.1/
perl -p -i.bak -e 's#__SUB__CWD__#'$(pwd)'#g' *.sql */*.sql
```

> 설치 명령어 예제
> 

```jsx
sqlplus system/systempw@connect_string
@mksample systempw syspw hrpw oepw pmpw ixpw shpw bipw users temp /your/path/to/log/ connect_str치
```

> 실제 설치 명령어
> 

```jsx
@mksample oracle_4U oracle_4U oracle_4U oracle_4U oracle_4U oracle_4U oracle_4U oracle_4U USERS TEMP /home/oracle/schemas/log/ 192.168.23.124:1521/ora12
```

> 삭제
> 

```jsx
sqlplus system/systempw@connect_string
@drop_sch.sql
```
