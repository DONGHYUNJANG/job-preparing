* swap 볼륨 추가
  $ dd if=/dev/zero of=/etc/swapfile bs=1024 count=5000000
    -- 5GB 생성
  $ mkswap /etc/swapfile
    -- Swap 파일로 포맷
  $ swapon /etc/swapfile
    -- Swap 공간으로 활성화
  $ /etc/fstab 파일에 추가
    /etc/swapfile          swap            swap    defaults        0 0

-----------------------------

항목    의미                     설정 이유
----------------------------------------------------------
nofile  열 수 있는 최대 파일 수
nproc   생성 가능한 프로세스 수
stack   프로세스 스택 크기
memlock 메모리에 고정 가능한 크기  HugePages 설정을 위해 필수. SGA(시스템 공유 메모리)가 디스크 스왑(Swap)으로 빠지지 않게 메모리에 '박제'해두는 용도입니다.

===============================================================================
== ASM Disk 구성
===============================================================================

-- 아래 1,2,5 번은 모든 node에서 수행
-- 아래 3,4 번은 1번 node 에서만 수행

  $ su -   ((root로 실행))

  1. configure
    $ /usr/sbin/oracleasm configure -i

  2. oracleasm 커널모듈 로딩
    $ /usr/sbin/oracleasm init

  3. 사용할 수 있는 Disk 확인 및 파티션 생성
    $ fdisk -l
    $ lsblk
    $ fdisk /dev/sdb
    $ fdisk /dev/sdc
    
    $ pvcreate /dev/sdb1 /dev/sdc1

  4. 생성된 파티션 디스크를 ASM 디스크로 할당
    $ oracleasm createdisk DATA /dev/sdb1
    $ oracleasm createdisk RECO /dev/sdc1
    $ oracleasm listdisks

  5. 모든 node에서 asm disk들을 접근하기 위해서 아래 커맨드를 모든 node에서 실행
    $ oracleasm scandisks
