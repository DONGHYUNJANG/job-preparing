### 1. 테이블 스키마 및 데이터 세팅
먼저 실습에 필요한 `department_sales` 테이블을 생성하고 데이터를 입력합니다. 이 데이터에는 매출액이 동일하거나, 매출액이 같을 때 다음 정렬 기준인 `sale_date`까지 동일한 케이스가 포함되어 있어 순위 함수들의 차이를 명확히 확인할 수 있습니다.

```sql
-- 테이블 생성
CREATE TABLE department_sales (
    sale_id SERIAL PRIMARY KEY,
    dept_name VARCHAR(50),
    employee_name VARCHAR(50),
    sales_amount NUMERIC(10, 2),
    sale_date DATE
);

-- 데이터 삽입
```

### 2. SQL 실습 문제

**[문제]**
위의 `department_sales` 테이블을 사용하여, **각 부서별(`dept_name`)**로 직원들의 매출 순위를 구하는 쿼리를 작성하세요. 

순위 결정 기준은 다음과 같습니다:
1.  **1순위 기준:** 매출액(`sales_amount`)이 높은 순서 (내림차순)
2.  **2순위 기준:** 매출액이 같다면 판매 날짜(`sale_date`)가 빠른 순서 (오름차순)

**요구사항:**
- `dept_name`, `employee_name`, `sales_amount`, `sale_date` 컬럼을 기본적으로 출력해야 합니다.
- 위에서 제시한 정렬 기준을 적용하여 다음 세 가지 방식의 순위를 별도의 컬럼으로 생성하세요.
    - `row_num`: `ROW_NUMBER()` 함수 사용
    - `rk`: `RANK()` 함수 사용
    - `drk`: `DENSE_RANK()` 함수 사용
- 최종 결과는 부서명(`dept_name`)별로 모아서 출력되도록 하세요.
