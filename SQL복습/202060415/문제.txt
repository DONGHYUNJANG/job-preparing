훈련을 위한 기초 데이터셋과 테이블 구조를 준비해 드립니다. 문제를 풀기 전에 오타를 하나 짚어드리자면, "줄수**잇니**"는 "줄 수 **있니**"가 올바른 맞춤법입니다! 😉

이 데이터는 2023년과 2024년 2개년도의 데이터를 포함하고 있어, 전년 동월 대비 성장률(YoY)을 계산하기에 적합합니다.

---

### 📊 Day 1: 실습 환경 구축

#### 1. 테이블 생성 (DDL)
부서 정보와 매출 일자, 금액을 담는 심플한 구조입니다.

```sql
CREATE TABLE dept_sales (
    dept_name VARCHAR(50),
    sale_date DATE,
    amount DECIMAL(18, 2)
);
```

#### 2. 샘플 데이터 삽입 (DML)
`영업1팀`과 `영업2팀`의 2023년~2024년 초반 데이터를 생성합니다.

```sql
INSERT INTO dept_sales (dept_name, sale_date, amount) VALUES
-- 2023년 데이터
('영업1팀', '2023-01-15', 1000), ('영업1팀', '2023-02-20', 1200), ('영업1팀', '2023-03-10', 1500),
('영업2팀', '2023-01-05', 800),  ('영업2팀', '2023-02-15', 900),  ('영업2팀', '2023-03-25', 1100),
-- 2024년 데이터 (성장 시나리오)
('영업1팀', '2024-01-12', 1200), ('영업1팀', '2024-02-18', 1300), ('영업1팀', '2024-03-05', 1800),
('영업2팀', '2024-01-08', 900),  ('영업2팀', '2024-02-22', 1100), ('영업2팀', '2024-03-28', 1200);
```

### 📝 Day 1 도전 과제 상세

**목표 결과물 형태:**
아래와 같이 부서별로 월별 매출액과 YoY(전년비 증가율)가 나란히 출력되어야 합니다.

| 부서명 | 월 | 2023년 매출 | 2024년 매출 | YoY (%) |
| :--- | :--- | :--- | :--- | :--- |
| 영업1팀 | 1 | 1000 | 1200 | 20.00 |
| 영업1팀 | 2 | 1200 | 1300 | 8.33 |
| ... | ... | ... | ... | ... |

**풀이 가이드 (힌트):**
1.  **1단계:** `EXTRACT` 또는 `TO_CHAR` 함수를 사용하여 연도와 월을 분리합니다.
2.  **2단계 (Pivot):** `CASE WHEN` 구문을 사용하여 연도별 매출을 컬럼으로 올립니다. (이때 `SUM`으로 집계)
3.  **3단계 (통계/Window):** 만약 연도별로 로우가 따로 있다면 `LAG` 함수를 써서 전년도 데이터를 가져오고, 위와 같이 한 줄에 피벗했다면 단순 산술 연산으로 YoY를 구합니다.
    * $YoY = \frac{(올해 매출 - 전년 매출)}{전년 매출} \times 100$

> [!TIP]
> **3차원적 사고 포인트**
> 단순히 값을 나열하는 것이 아니라, "특정 시점의 데이터를 이전 시점의 데이터와 어떻게 매칭시킬 것인가"에 집중해 보세요.
