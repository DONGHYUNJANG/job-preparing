### 📝 실전 문제

위의 `sales_records` 테이블을 사용하여 다음 조건에 맞는 결과 집합을 출력하는 SQL 쿼리를 작성하세요.

1.  **부서 비중 (Dept_Ratio):** * 전체 부서의 총 매출 합계 대비, 해당 사원이 속한 부서의 총 매출 합계가 차지하는 비율을 계산하세요.
    * 예: (영업1팀 전체 합계 / 모든 팀 전체 합계)

2.  **부서 내 매출 순위 백분위 (Sales_Percent_Rank):** * **부서 내에서** 해당 사원의 매출액이 상위 몇 %에 위치하는지 0과 1 사이의 값으로 계산하세요.
    * `PERCENT_RANK()` 함수를 사용하세요. (0에 가까울수록 상위권)

3.  **부서 내 누적 분포 (Sales_Cume_Dist):**
    * **부서 내에서** 해당 사원의 매출액보다 작거나 같은 값의 비율을 계산하세요.
    * `CUME_DIST()` 함수를 사용하세요.

4.  **정렬 및 출력:**
    * `dept_name` (오름차순)과 `sales_amount` (내림차순)으로 정렬하세요.

### 💡 OCP 시험 관련 개념 설명 (Oracle vs PostgreSQL)

**1. Window Functions as Ratios**
표준 SQL에서 비율을 구할 때는 `SUM(column) OVER()`를 분모로 사용합니다. Oracle과 PostgreSQL 모두 동일한 문법을 사용하지만, 나눗셈 연산 시 `NUMERIC` 타입이 아닌 경우 소수점이 절사될 수 있으므로 주의해야 합니다.

**2. 분포 함수 (PERCENT_RANK vs CUME_DIST)**
* **PERCENT_RANK:** 제일 먼저 나오는 행은 0, 마지막 행은 1을 반환합니다. 식은 $\frac{rank - 1}{rows - 1}$ 입니다.
* **CUME_DIST:** 누적 분포를 나타내며, 현재 행의 값보다 작거나 같은 행의 수를 전체 행 수로 나눕니다. 식은 $\frac{count\_of\_rows\_with\_value \le current\_row\_value}{total\_rows}$ 입니다.
