부분을 보면 클러스터가 오라클을 죽였다고 한다.
또한 메모리 점유율과cpu가 매우 빠듯하므로 이것이 커널에 문제를 일으켰을 가능성이 높아 프리징되었을 것이라고 한다.
그래서 SGA를 줄여보기로 했다. 이제 다시 시간을 들여 기다려봐야할것 같다.

-- SGA와 PGA의 전체적인 설정값 확인
show parameter target

-- 더 상세한 실제 사용량 확인
select name, value/1024/1024 as "Size(MB)" 
from v$parameter 
where name in ('sga_target', 'sga_max_size', 'pga_aggregate_target');


리눅스 8기가 메모리 기준
-- 1. SGA 최대 크기와 목표 크기 설정 (예: 2GB로 제한)
alter system set sga_max_size = 2G scope=spfile;
alter system set sga_target = 2G scope=spfile;

-- 2. PGA 목표 크기 설정 (예: 500MB로 제한)
alter system set pga_aggregate_target = 500M scope=spfile;

-- 3. (중요) 설정 적용을 위해 DB 재시작
shutdown immediate;
startup;
